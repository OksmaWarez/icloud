# Sideloading without Setup.app

Mitigating Setup.app causes a lot of issues, including IPA sideloading. This page serves as a list of workarounds on how to sideload apps onto an iDevice with setup.app mitigated.

## Signing in with an Apple ID

Depending on the bypass method, signing in with an Apple ID should allow sideloading with Sideloadly, PlumeImpactor, etc.

## Sideloading with Appsync Unified

iOS 6.0-9.3.6 have jailbreak methods that don't utilize sideloading, and instead use Webkit or similar exploits.
Jailbroken users can install Appsync Unified and use Adhoc signing when sideloading applications with Sideloadly.

## Sideloading with AFC2 and IPA Installer

Jailbroken users can move IPA files from their computer by using an AFC2 browser and installing them from within the device using IPA Installer.
